
# TechNova Responsive Email Template

## Overview
A promotional email template for a fictional technology brand,
built using HTML5 and CSS3.

## Features
- Responsive email layout
- Promotional content and call-to-action button
- Footer with an unsubscribe link
- Mobile-specific CSS media query
- Basic accessibility considerations

## Technologies
- HTML5
- CSS3

## Testing
Tested in a web browser at mobile, tablet, and desktop viewport sizes.

## How to Run
1. Clone or download this repository.
2. Open index.html in a web browser.
3. Use browser developer tools to test different screen widths.

## Note
This is a demonstration project. Links use placeholder URLs.
Browser viewport testing does not guarantee compatibility
with Gmail, Outlook, or other email clients.
